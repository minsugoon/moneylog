# Moneylog 디자인 가이드 (시안용)

- 버전: v1.0 / 최종 수정: 2026-11-01 (구현 상태 기준: 단계 8까지)
- 용도: Claude 채팅 등에서 디자인 시안을 만들 때 "지금 앱이 어떻게 생겼는지"를 한 번에 넘기기 위한 문서. 코드와 다르면 코드가 맞다.
- 같이 보면 좋은 것: 화면 샘플 한 장짜리 페이지(현황판처럼 만든 "Moneylog 화면 샘플" 아티팩트), 앱 주소 moneylog.vibecodelab.dev

## 0. 시안을 만들 때 먼저 알아둘 것
- 개인용 가계부 PWA. 한국어 UI, 금액은 원화(₩ 대신 `12,000원` 표기). 폰 우선, PC에서도 같은 앱.
- **분류(식비/교통 등), 예산 설정, 은행·카드사 자동 연동은 없다.** 시안에 넣지 않는다. "어디에 얼마 썼는지"만 본다.
- 입력은 최소 터치가 목표. 붙여넣기·사진으로 읽은 내용은 항상 **미리보기 → 확인 → 저장** 순서.
- 앱에 없는 기능을 새로 그릴 때는 "제안"으로 표시해 달라고 요청한다 (임의로 기능을 추가하지 않는 프로젝트 규칙).
- 시안의 기준 화면: **아이폰 15 Pro, CSS 폭 393px × 852px**. 그다음 PC(1280px 이상).
- 지금은 **라이트 모드만** 있다. 다크 모드는 마지막 단계(12)에서 만든다.

## 1. 색
Tailwind CSS v4 기본 팔레트를 쓰고, 브랜드 색 둘만 직접 정했다. (헥스는 화면에서 보이는 근사값)

| 역할 | 값 | 어디에 쓰나 |
|------|-----|-------------|
| 브랜드 `brand` | `#2C4DD6` | 앱 이름, 주 버튼, 선택된 칩, 활성 탭, 막대그래프, 링크성 글자 |
| 앱 배경 `app-bg` | `#F2F4F9` | 화면 전체 바탕 (카드 뒤) |
| 카드/표면 | `#FFFFFF` | 카드, 하단 탭, 사이드바, 입력창, 창(Dialog) |
| 본문 글자 | `#1F2937` (gray-800) | 제목, 금액, 결제명 |
| 보조 글자 | `#4B5563`(600) / `#6B7280`(500) | 라벨, 설명, 날짜, 결제수단 이름 |
| 테두리 | `#D1D5DB`(gray-300) 입력·보조 버튼, `#E5E7EB`(200) 구분선·탭 경계, `#F3F4F6`(100) 목록 구분선 |
| 위험/취소 | 글자 `red-600/700`, 바탕 `red-50` | 취소 배지, 오류 상자, 삭제 버튼(`red-600` 채움), 취소 금액(마이너스) |
| 성공/무이자 | 글자 `green-800`, 바탕 `green-50` | 무이자 배지, 저장 완료 안내 |
| 고정지출 | 글자 `blue-800`, 바탕 `blue-50` | 고정 배지 |
| 주의/중복 가능 | 글자 `amber-800`, 바탕 `amber-100` | 중복 가능 배지, 하루 정리 글 바탕(`amber-50`) |
| 선택됨(사이드바) | 바탕 `brand` 10%, 글자 `brand` | 사이드바 활성 메뉴 |
| 창 뒷배경 | 검정 40% | Dialog |

- 규칙: **색만으로 구분하지 않는다.** 상태는 항상 글자도 함께 쓴다 (예: `취소`, `중복`, `⚠ 실적 제외 가능 · 사유`).

## 2. 글자
- 글꼴: 따로 지정하지 않고 **시스템 기본 글꼴**(Tailwind 기본 sans: 아이폰은 SF/Apple SD Gothic Neo, 안드로이드는 Noto Sans KR, 윈도우는 맑은 고딕). 시안에서 다른 글꼴을 쓰고 싶으면 제안으로 표시.
- 크기(Tailwind): 앱 이름 `text-xl bold brand` / 화면 제목 `text-lg bold` / 본문·입력 `text-base`(16px) / 보조 `text-sm`(14px) / 작은 글씨·배지 `text-xs`(12px) / 큰 합계 `text-3xl bold`(30px).
- **입력창 글자는 반드시 16px 이상** (아이폰이 입력할 때 화면을 확대하지 않도록).
- 금액은 숫자 폭을 맞춘 글자(`tabular-nums`), 천 단위 콤마, 뒤에 `원`.
- 글을 쓰는 입력칸(결제명·메모·하루 정리·별칭)은 한글 키보드가 기본(`lang="ko"`).

## 3. 모양·크기·간격
- 눌러야 하는 것(버튼·칩·목록 줄·입력창)은 **높이 44px 이상** (`min-h-11`).
- 모서리: 카드 `16px`(`rounded-2xl`) / 버튼·입력창·미리보기 줄 `8px`(`rounded-lg`, 미리보기 줄은 12px) / 칩·배지 `완전 둥글게`(`rounded-full`) / 창(Dialog) 위쪽 `16px`.
- 그림자: 카드만 아주 약하게(`shadow-sm`). 창은 `shadow-xl`.
- 간격: 화면 좌우 여백 `16px`(PC 본문 `24px`), 카드 안쪽 `20px`, 카드 사이 `16px`, 폼 항목 사이 `16px`, 칩·버튼 사이 `8px`.
- 본문 폭: 한 열 화면은 가운데 정렬, 최대 `576px`(`max-w-xl`).
- 아이콘: 이모지를 쓴다 (탭: 📋 내역 / ✏️ 입력 / 📊 보기 / ⚙️ 설정). 별도 아이콘 세트 없음.

## 4. 화면 틀 (폭에 따라 배치만 바뀐다)
| 폭 | 배치 |
|----|------|
| 모바일 ~767px | 한 열 + **하단 탭 4개**(높이 64px, 아이폰 홈 인디케이터 영역 `safe-area` 피함). 위에 앱 이름 `Moneylog`(브랜드 색) |
| 태블릿 768~1099px | **왼쪽 사이드바**(폭 224px, 흰색, 앱 이름 + 메뉴 4개) + 본문 |
| PC 1100px~ | 사이드바 + 본문 + **오른쪽 "빠른 입력" 패널**(폭 384px, 흰색, 항상 보임) |

- 사이드바 메뉴: 높이 44px, 활성은 `brand` 10% 바탕 + 굵은 브랜드 글자.
- 하단 탭: 활성은 굵은 브랜드 글자, 비활성은 회색(500). 아이콘 위, 글자 아래.
- 미리보기 줄: 모바일·PC 모두 줄마다 카드 형태(3줄: 사용일+결제명 / 금액+할부+취소 / 결제수단).

## 5. 공통 부품
- **주 버튼**: 브랜드 색 채움, 흰 글자 굵게, 높이 44px, 모서리 8px. **보조 버튼**: 흰 바탕 + 회색 테두리. **위험 버튼**: 빨강 채움(삭제 확인 창에서만).
- **칩**: 둥근 알약. 선택되면 브랜드 채움 + 흰 굵은 글자, 아니면 흰 바탕 + 회색 테두리. 입력 방식·보기 기준·결제수단·날짜(오늘/어제)에 쓴다.
- **입력창**: 흰 바탕, 회색 테두리, 포커스 시 브랜드 테두리 + 옅은 링. 라벨은 위에 `text-sm bold` 회색.
- **금액 입력**: 숫자 키패드, 천 단위 콤마.
- **카드**: 흰 바탕, 모서리 16px, 약한 그림자, 안쪽 20px. 카드 제목은 `text-sm bold` 회색 또는 `text-base bold` 진한 회색.
- **배지**(내역 줄·미리보기): `취소`(빨강), `무이자`(초록), `고정 · 통신`(파랑), `중복`(진한 빨강 채움 + 흰 글자), `중복 가능`(옅은 주황), `입금`(회색), `실패`(옅은 빨강). 카드 실적(단계 9~10)이 들어오면 `⚠ 실적 제외 가능 · 사유`를 카드(결제수단)에만 붙인다.
- **창(Dialog)**: 모바일은 아래에서 올라오는 시트(위 모서리 16px), 넓은 화면은 가운데. 바깥을 눌러도 안 닫힘. 삭제는 반드시 확인 창.
- **막대**: 가로 막대(높이 8px), 바닥 줄은 `gray-100`, 채움은 브랜드. 값은 글자로도 항상 표시.
- **빈 화면/로딩/오류**: 친절한 한국어 문장. 빈 화면은 흰 카드 가운데 정렬 회색 글자(`text-sm`), 오류는 `red-50` 상자 + "다시 불러오기" 보조 버튼.

## 6. 결제수단 표시 형식 (앱 전체 공통)
- 통장 `카카오뱅크 · 월급통장 (1234)` / 카드 `신한카드 · 생활카드 (5678)` / 현금 `현금`. 끝 4자리가 없으면 괄호 생략. 전체 카드·계좌번호는 절대 보여주지 않는다.

## 7. 화면별 구성 (지금 구현된 것)
### 내역 (홈)
달 이동(‹ 2026년 11월 › + 이번 달) → 보기 기준 칩(사용일 기준 / 월 납부액 기준) + 설명 한 줄 → **월 합계 카드**(큰 금액, 지출 N건) → (이어진 할부 묶음) → **날짜 카드**들: 날짜+그날 합계, 하루 정리(있으면 노란 상자, 없으면 `+ 하루 정리`), 내역 줄. 내역 줄: 결제명(+메모 작은 글씨) / 결제수단·배지 / (할부면 `12개월 할부 · 3/12회차 · 월 …· 잔액 …`) / 오른쪽 금액(취소는 빨강 마이너스).
### 입력
상단 칩 3개: **직접 입력 / 문자 붙여넣기 / 사진 입력**.
- 직접 입력(PC에서는 오른쪽 빠른 입력 패널과 같은 폼): 사용일(날짜 + 오늘/어제 칩) → 결제수단(드롭다운 + `🔽 펼치기`로 칩 전체) → **고정지출 불러오기**(지난 고정지출 `결제명 · 금액 · 날짜 · 종류`, 5줄 + 더 보기) → 결제명 → 금액·할인 → 할부 → 체크: 취소 건 / 무이자 할부 / 고정지출(+종류, `고정 지출 이름 설정하기`) → 메모(200자) → 저장. 아래 카드: **하루 정리**(자동 저장).
- 문자 붙여넣기: 큰 입력칸 → 읽기 → 미리보기.
- 사진 입력: 첫 사용 때 동의 창, 사용량(이번 달 n/20장), `카드사 앱 캡처 / 영수증` 칩, 결제수단 선택, 이미지 고르기(영수증은 `영수증 사진 찍기` / `사진 고르기`) → 읽기 → 미리보기.
- **미리보기**: 결제수단 일괄 지정 → 줄 카드들(저장 대상 체크 + 상태 배지, 사용일·결제명, 금액·할부·취소, 결제수단, 고정지출 체크+종류) → `저장 N건 / 제외 N건 / 실패 N건` → 저장 / 다시 붙여넣기.
### 보기
칩 3개 순서: **기간별 → 결제수단별 → 고정지출**(처음엔 기간별). 합계 카드 + 가로 막대 목록. 고정지출 보기는 총합 카드 + 종류별 소계 카드(내역 목록). 단계 9에서 "카드 실적" 탭이 추가된다.
### 설정
카드들이 세로로: 결제수단(+ 추가, 순서 바꾸기·수정·사용중지·삭제) → 고정지출 규칙(키워드·종류·삭제, 키워드 추가, 이미 입력한 고정지출에서 고르기) → AI 입력(동의·사용량) → 내 계정(이메일, 로그아웃).
### 로그인
구글로 로그인(기본) + 이메일·비밀번호(예비). 매직링크 없음.

## 8. 앞으로 들어올 화면 (시안 요청 가능, 아직 없음)
- 단계 9 **카드 실적**: 프로그램(카드별 월 목표) 카드에 진행률 막대, 남은 금액, 하루 필요 금액, 받을 혜택 목록. PC에서는 프로그램 카드를 2열. 내역 화면 위쪽에 실적 요약 띠. 반드시 "내 입력 기준 참고용" 문구.
- 단계 10 **실적 제외**: `⚠ 실적 제외 가능 · 사유` 배지(카드 내역에만), 배지 설명 창, "실적 포함/제외로 확정".
- 단계 11 엑셀/CSV 업로드(열 매핑 → 기존 미리보기 재사용), 단계 12 다크 모드·정식 아이콘.
- 임시 PWA 아이콘 4종이 있고 정식 아이콘은 단계 12.

## 9. 시안 의뢰할 때 쓸 문구 (예시)
> 첨부한 DESIGN.md가 지금 앱의 디자인이야. 이 틀(색·글자·간격·부품)을 지키면서 [화면 이름]의 시안을 아이폰 15 Pro(393px) 기준으로 만들어줘. 앱에 없는 기능은 "제안"이라고 표시해줘. 분류·예산 기능은 넣지 마.
