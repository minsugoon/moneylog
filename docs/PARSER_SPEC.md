# Moneylog 입력 인식(파서) 명세

- 버전: v0.5 / 최종 수정: 2026-10-09
- 관련 코드: `src/utils/parsers/` (카드사·은행별 파일 + 테스트)
- 관련 기능: F9(카드앱 붙여넣기), F10(문자), F11(엑셀/CSV), F12(중복 방지)

## 1. 입력 방식 4가지
| 방식 | 사용자가 하는 일 | 결과 |
|------|------------------|------|
| 직접 입력 | 폼에 입력 | 바로 저장 |
| 카드앱 붙여넣기 | 이용내역 화면을 복사해 붙여넣기 | 미리보기 → 확인 → 저장 |
| 결제 문자 붙여넣기 | 문자 여러 건을 한꺼번에 붙여넣기 | 건별 분리 → 미리보기 → 확인 → 저장 |
| 엑셀/CSV 업로드 | 카드사에서 내려받은 파일 선택 | 열 매핑 → 미리보기 → 확인 → 저장 |

## 2. 파서 결과 모양 (모든 파서 공통)
```ts
type ParsedRow = {
  date: string | null;          // 'YYYY-MM-DD'
  merchant: string;             // 결제명
  amount: number | null;        // 0 이상 정수(원)
  installment: number;          // 할부 개월, 일시불은 1
  isCancel: boolean;            // 취소 건 여부
  interestFree: boolean;        // 무이자 할부 문구가 있으면 true
  direction: 'expense' | 'income'; // 통장 문자의 출금/입금
  accountHint: string | null;   // 문구 속 카드사/은행명, 끝 4자리 (등록된 결제수단 자동 선택에 사용)
  raw: string;                  // 원문 (실패 시 사용자에게 그대로 보여줌)
  status: 'ok' | 'failed';
};
```

## 3. 공통 규칙
- 파서는 카드사/은행별로 파일을 나눈다. (`shinhan.ts`, `kakaobank.ts` 식) 새 형식이 생기면 **기존 파서를 고치지 말고 파일을 추가**한다.
- 인식 실패한 줄은 버리지 않고 `status: 'failed'`로 미리보기에 빨간색으로 보여주고, 사용자가 직접 고치게 한다.
- 저장 전에는 항상 **미리보기 → 사용자 확인**을 거친다.
- 금액은 콤마·"원"을 제거해 정수로 바꾼다. 소수점은 쓰지 않는다.
- 연도가 없는 날짜(`09/05`)는 **오늘 기준 가장 가까운 과거 날짜**로 해석한다. (예: 1월에 `12/30`이면 작년)
- 전체 카드번호·계좌번호가 문구에 있어도 저장하지 않는다. 끝 4자리만 `accountHint`로 쓴다.

## 4. 인식 규칙

### 카드 결제 문자
예시(임의 값): `[Web발신] 신한카드(1234)승인 홍길동 12,300원 일시불 09/05 14:20 스타벅스`
- 카드사명, 끝 4자리, 금액, 할부(일시불=1, "3개월"=3), 날짜, 가맹점을 추출한다.
- 문구에 `취소`가 있으면 `isCancel = true`.
- 문구에 `무이자`가 있으면 `interestFree = true`.

### 통장 거래 문자
예시(임의 값): `[Web발신] 신한은행 09/05 14:20 출금 50,000원 잔액 1,234,000원 (통신요금)`
- `출금` → `direction: 'expense'`, 지출로 저장 대상
- `입금` → `direction: 'income'`, **기본 해제 상태**로 미리보기에 표시 (지출이 아니므로)
- 문구 속 은행명·끝 4자리가 등록된 통장과 일치하면 해당 통장을 자동 선택
- 잔액은 저장하지 않는다.

### 카드앱 붙여넣기
- 줄 단위·덩어리 단위로 날짜/가맹점/금액/할부를 추출한다.
- 카드사마다 모양이 달라서 실제 샘플로 파서를 만든다. (단계 7 시작 전 샘플 준비)

### 엑셀/CSV
- 첫 행을 읽어 열 이름을 자동 매핑한다. (날짜, 가맹점/이용처, 금액, 할부, 할인)
- 매핑이 틀리면 드롭다운으로 수정하고, **결제수단별로 매핑을 저장**해 다음에 자동 적용한다.
- 라이브러리: `papaparse`(CSV), `xlsx`(엑셀)

## 5. 미리보기 화면
- PC(1100px 이상)는 넓은 표, 모바일은 줄마다 카드 형태. 담는 정보와 동작은 같다.
- 행마다 체크박스(저장 대상 선택), 각 칸 수정 가능
- 결제수단 **일괄 지정** (붙여넣기·파일·문자 공통)
- 상태 표시
  - `중복`: 이미 저장된 내역 → 기본 해제
  - `입금`: 통장 입금 → 기본 해제
  - `실패`: 인식 실패 → 빨간색, 직접 수정 필요
  - `⚠ 실적 제외 가능 · 사유`: 카드 내역에 제외 키워드가 있을 때 (`PERFORMANCE_SPEC.md` 6장)
- 고정지출 규칙(`fixed_rules`)에 맞는 결제명은 자동으로 고정지출 종류를 채운다. (수정 가능)
- 맨 아래에 "저장 N건 / 제외 N건 / 실패 N건" 요약
- 메모(`memo`)와 하루 정리는 파서가 만들지 않는다. 저장한 뒤 내역 상세에서 추가한다.

## 6. 중복 방지
- `import_hash` = 날짜 + 결제명 + 금액 + 결제수단으로 만든 지문
- 같은 내용을 다시 붙여넣으면 "중복"으로 표시하고 기본 해제한다.
- 같은 날 같은 가게에서 같은 금액을 두 번 결제한 경우를 대비해, 미리보기에서 사용자가 체크해 저장할 수 있게 한다.

## 7. 샘플과 테스트
- 파서마다 `파일명.test.ts`를 같이 만든다.
- 샘플은 **이름·번호·금액을 임의 값으로 바꾼 것**만 쓴다. 실제 개인정보는 코드·GitHub에 넣지 않는다.
- 최소 테스트 목록

| 상황 | 기대 결과 |
|------|-----------|
| 카드 승인 문자 1건 | 날짜·금액·가맹점·끝 4자리 추출 |
| 문자 여러 건 붙여넣기 | 건별로 분리 |
| 3개월 할부 문자 | `installment = 3` |
| 취소 문자 | `isCancel = true` |
| "무이자" 포함 문자 | `interestFree = true` |
| 통장 출금 문자 | `direction = 'expense'` |
| 통장 입금 문자 | `direction = 'income'`, 기본 해제 |
| 연도 없는 날짜 | 가장 가까운 과거 날짜 |
| 알 수 없는 형식 | `status = 'failed'`, 원문 보존 |
| 같은 내역 두 번 | 두 번째는 중복 |

## 8. 준비할 샘플 (단계 7 시작 전)
- 주로 쓰는 카드 1~2개의 앱 이용내역 복사본 (한 달 치)
- 카드 결제 문자 5건, 취소 문자 2건, 할부 문자 2건
- 은행 출금 문자 3건, 입금 문자 2건
- 카드사에서 내려받은 엑셀/CSV 1개씩
- 이름·카드번호·계좌번호·금액은 임의 값으로 바꿀 것
