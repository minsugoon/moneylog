# Moneylog 카드 실적 · 제외 항목 명세

- 버전: v0.5 / 최종 수정: 2026-10-09
- 관련 코드: `src/utils/performance.ts`, `src/utils/exclusion.ts` (각각 테스트 파일 필수)
- 관련 표: card_programs, card_benefits, exclusion_rules, transactions → `DATA_MODEL.md`

## 1. 개념
- **실적 프로그램**: "이 카드를 한 달에 N원 이상 써야 한다"는 조건 한 묶음. 카드 1장에 여러 개 가능.
- **혜택**: 프로그램을 달성했을 때 받는 할인. 프로그램 1개에 여러 개, 단계별(30만원/50만원 등) 가능.
- 예시
  - 프로그램: `LG베스트샵 하나카드` / 월 최소 300,000원
    - 혜택 1: 정수기 렌탈비 할인 10,000원 (30만원 이상)
    - 혜택 2: 통신비 할인 5,000원 (30만원 이상)
    - 혜택 3: 렌탈비 추가 할인 10,000원 (50만원 이상)
- 카드마다 조건이 다르므로 **코드에 고정하지 않고 사용자가 직접 설정**한다.

## 2. 설정 항목

### 프로그램
| 항목 | 설명 | 기본값 |
|------|------|--------|
| 대상 카드 | 등록된 결제수단 중 카드 | 필수 |
| 프로그램 이름 | 예: LG베스트샵 하나카드 | 필수 |
| 월 목표 금액 | 실적 인정 최소 사용액 (0 이하 저장 불가) | 필수 |
| 측정 방식 | `당월` 이번 달 사용액이 이번 달 혜택 결정 / `전월` 지난달 사용액이 이번 달 혜택 결정 | 전월 |
| 측정 시작일 | 매월 집계 시작일 (1이면 달력 기준) | 1 |
| 할부 인정 방식 | `전액` 사용한 달에 전체 인정 / `월납부액` 매달 나눠 인정 | 전액 |
| 개별 제외 키워드 | 이 프로그램에서만 뺄 추가 단어 | 없음 |
| 제외 항목별 처리 방식 | 제외 항목 10종마다 `제외`/`표시만`/`무시` | A등급 `제외`, B등급 `표시만` |
| 사용 여부 | 끄면 현황에서 숨김 | 켬 |

### 혜택
| 항목 | 설명 |
|------|------|
| 혜택 이름 | 예: OOO 정수기 렌탈비 할인 |
| 필요 실적 | 이 혜택의 필요 사용액 (비우면 프로그램 목표 금액) |
| 혜택 금액 | 예: 10,000원 |
| 혜택 종류 | 렌탈 / 통신 / 구독 / 보험 / 기타 |
| 연결 결제명 | 혜택이 적용되는 고정지출의 결제명 키워드 (선택) |
| 메모 | 자유 입력 (예: 전월 실적 충족 시 익월 청구서에서 차감) |

## 3. 계산 규칙

### 3-1. 내역별 실적 인정 판단 순서
위에서부터 먼저 맞는 것이 적용된다. **사용자 확정이 항상 이긴다.**
1. `performance_override = 'include'` → 포함
2. `performance_override = 'exclude'` → 제외
3. 취소 건(`is_cancel`) → 차감 (취소가 접수된 달의 실적에서 뺀다)
4. 무이자 할부 건(`interest_free`)이고 프로그램의 `interest_free` 처리 방식이 `제외` → 제외
5. 결제명에 제외 키워드(기본 사전 + 프로그램 개별 키워드)가 있고 해당 항목 처리 방식이 `제외` → 제외
6. 그 외 → 포함 (처리 방식이 `표시만`이면 포함하되 ⚠ 배지만 표시)

처리 방식이 `무시`인 항목은 배지도, 계산 제외도 하지 않는다.

### 3-2. 금액·기간
- 건별 인정 기준액 = 이용금액 - 할인
- 할부 `전액`: 사용한 달에 실결제액 전체 / `월납부액`: 월 납부액만 인정
- 측정 기간: 시작일 1이면 달력 기준(1일~말일), 15라면 15일~다음 달 14일
- 측정 방식 `전월`: 화면에 "이번 달 실적 → 다음 달 혜택"을 함께 표시

### 3-3. 결과 지표
| 지표 | 계산 |
|------|------|
| 실적 인정액 | 인정 대상 내역 합계 (취소 건 차감) |
| 진행률 | 실적 인정액 / 월 목표 금액 (막대는 100% 제한, 숫자는 실제 값) |
| 남은 금액 | max(0, 월 목표 금액 - 실적 인정액) |
| 하루 필요 금액 | 남은 금액 / 남은 일수 (마지막 날 포함, 원 단위 올림) |
| 상태 | 달성(100% 이상) / 진행 중 / 주의(남은 일수 7일 이하이고 진행률 70% 미만) |
| 받을 혜택 합계 | 필요 실적 이하로 달성한 혜택 금액의 합 |
| 다음 단계 안내 | 다음 혜택까지 남은 금액과 추가 혜택 (예: "50만원까지 120,000원 남음, 추가 10,000원") |
| 제외 가능 합계 | `표시만` 상태로 포함된 내역의 건수·합계. 예: "실적 310,000원 (제외 가능 내역 40,000원 포함)" |

## 4. 화면

### 보기 > 카드 실적 탭
- 프로그램마다 카드 한 장: 카드명, 프로그램 이름, 측정 기간, 진행률 막대, `현재액 / 목표액`, 남은 금액, 하루 필요 금액, 상태 배지
- 혜택 목록: 달성은 체크, 미달성은 "○○원 남음" / 받을 혜택 합계
- "제외 가능 내역 N건 / 합계 ○○원 포함됨" 안내 (누르면 해당 내역으로 이동)
- 카드를 누르면 **포함된 내역 / 제외된 내역**이 나뉘고, 각 내역에서 포함·제외 확정 가능
- 월 이동으로 지난달 실적 조회
- "내 입력 기준 참고용" 문구 표시
- PC(1100px 이상)에서는 프로그램 카드를 2열로 나란히 배치한다. 모바일은 세로 한 줄.

### 내역 화면 상단 요약 띠
- "주의" 상태와 임박한 것 위주로 1~2개 표시, 누르면 카드 실적 탭으로 이동

### 설정 > 카드 실적·혜택 관리
- 프로그램·혜택 추가/수정/삭제/사용중지
- 카드가 없으면 "먼저 카드를 등록해주세요" 안내와 바로가기
- 삭제 시 "내역은 삭제되지 않습니다" 안내 후 확인

### 고정지출 보기 연계
- 연결 결제명이 설정된 고정지출 옆에 `실적 달성 시 -10,000원` 표시
- 소계에서 "예상 할인 반영 전/후" 금액 표시

## 5. 예외·주의
- 카드사마다 제외 항목이 달라 앱이 정확히 알 수 없다. **처리 방식 설정과 내역별 확정으로 사용자가 보정**한다.
- 이 실적은 **내가 입력한 내역 기준**이다. 카드사 공식 실적과 다를 수 있다.
- 입력하지 않은 결제는 실적에 잡히지 않는다.
- **첫 달에는 카드사 앱의 실적과 이 앱의 수치를 대조해 설정을 맞춘다.**

## 6. 실적 제외 가능 항목

### 목적
실적에서 빠질 수 있는 결제를 **"제외될 수 있음"으로 미리 표시**해 실적을 잘못 계산하고 안심하는 일을 막는다.

### 제외 항목 10종과 기본 키워드
기본 키워드는 첫 로그인 때 자동 등록(`is_default = true`)하고, 사용자가 추가·삭제·끄기를 할 수 있다. 결제명에 키워드가 **포함**되면 해당한다.

**A등급: 거의 모든 카드에서 제외 (기본 처리 방식 `제외`)**
| 코드 | 항목 | 기본 키워드 예시 |
|------|------|------------------|
| loan | 현금서비스·카드론 | 현금서비스, 카드론, 단기카드대출, 장기카드대출 |
| fee | 연회비·수수료·이자 | 연회비, 수수료, 할부수수료, 이자, 연체료, 알림서비스, SMS |
| cancel | 결제 취소 | 취소, 승인취소, 매입취소 (키워드 + `is_cancel` 칸 병행) |
| tax | 국세·지방세 | 국세, 지방세, 소득세, 부가가치세, 취득세, 재산세, 자동차세, 위택스, 홈택스, 세외수입 |
| fine | 관세·과태료·벌금·체납금 | 관세, 과태료, 벌금, 범칙금, 체납, 통행료미납 |

**B등급: 대부분 제외되나 카드마다 다름 (기본 처리 방식 `표시만`)**
| 코드 | 항목 | 기본 키워드 예시 | 비고 |
|------|------|------------------|------|
| giftcard | 상품권·선불충전 | 상품권, 문화상품권, 기프티콘, 기프트카드, 선불카드, 네이버페이 충전, 카카오페이 충전, 머니충전 | |
| utility | 아파트 관리비·도시가스 | 관리비, 아파트관리, 도시가스, 가스공사 | 자동이체 특화 카드는 인정 → 해당 프로그램만 `무시` |
| school | 학교 납입금·등록금 | 등록금, 수업료, 학교납입, 입학금, 학부모부담금 | |
| insurance4 | 4대 사회보험료 | 건강보험, 국민연금, 고용보험, 산재보험, 사회보험 | 민간 보험료와 구분 |
| interest_free | 무이자 할부 | (키워드 없음) | 입력 시 체크, 카드앱 내역에 "무이자" 문구가 있으면 자동 체크 |

### 처리 방식 3가지
| 방식 | 의미 |
|------|------|
| 제외 | 실적 계산에서 뺀다. 배지 표시. |
| 표시만 | 실적 계산에는 포함하되 `⚠ 실적 제외 가능` 배지를 표시하고 합계를 따로 안내. |
| 무시 | 신경 쓰지 않는다. 배지도 계산 제외도 없음. |

### 배지 표시 규칙
- 위치: 내역 목록, 입력 미리보기(붙여넣기/문자/파일), 카드 실적 상세 목록
- 문구: `⚠ 실적 제외 가능 · 세금` 처럼 **사유(항목명)를 함께** 표시
- 색상: A등급은 진한 경고색, B등급은 연한 경고색. 색만으로 구분하지 않고 "제외 가능성 높음 / 카드에 따라 다름" 문구도 함께
- 배지를 누르면 설명창: "이 결제는 [세금] 항목이라 대부분의 카드에서 실적에서 제외됩니다." + 버튼 `실적 제외로 확정` / `실적 포함으로 확정` / `그대로 두기`
- 확정하면 `performance_override`에 저장, 이후 자동 판단보다 우선. 확정된 내역에는 `확정됨` 표시
- 현금·통장에는 배지를 표시하지 않는다. (실적은 카드에만 해당)
- 해당 카드에 실적 프로그램이 없으면 배지를 표시하지 않는다. 단, 입력 미리보기에서는 "제외 항목일 수 있음" 안내만 가볍게 표시

### 규칙 관리 화면 (설정 > 실적 제외 규칙)
- 항목 10종을 A/B등급으로 나눠 보여주고, 항목별 키워드를 추가·삭제·끄기
- "기본값으로 되돌리기" 버튼
- 처리 방식은 프로그램 설정에서 카드별로 바꾼다. (여기서는 키워드만 관리)

### 인식 한계 (화면에 안내할 내용)
- 결제명만으로 판단하므로 **놓치거나 잘못 표시할 수 있다.** (예: "국세청"이 아니라 "정부24"로 보이는 경우)
- "무이자 할부"는 결제명에 안 나오는 경우가 많아 직접 체크가 필요하다.
- 제외 기준은 카드사·상품마다 다르고 바뀔 수 있다. **정확한 기준은 카드 약관과 카드사 앱으로 확인한다.**
- 자주 틀리는 것은 키워드를 추가해 보정한다.

## 7. 테스트 목록 (테스트 파일에 반드시 포함)
| 상황 | 기대 결과 |
|------|-----------|
| "국세청 지방세 납부" | tax로 판정 |
| "문화상품권 구입" | giftcard로 판정 |
| 취소 건 | 해당 달 실적에서 차감 |
| 사용자가 `include` 확정한 세금 내역 | 포함 (자동 판정보다 우선) |
| 사용자가 `exclude` 확정한 일반 내역 | 제외 |
| 처리 방식 `무시`인 항목 | 배지 없음, 계산 포함 |
| 처리 방식 `표시만`인 항목 | 계산 포함 + 제외 가능 합계에 집계 |
| 목표 300,000원, 인정액 310,000원 | 진행률 103%, 막대 100%, 남은 금액 0, 달성 |
| 목표 300,000원, 인정액 100,000원, 남은 일수 10 | 하루 필요 20,000원 |
| 남은 일수 5, 진행률 50% | 상태 "주의" |
| 혜택 30만/50만 단계, 인정액 420,000원 | 30만 혜택 달성, 다음 단계 안내 "50만원까지 80,000원 남음" |
| 측정 시작일 15 | 15일~다음 달 14일 집계 |
| 할부 `전액` vs `월납부액` | 인정액이 각각 전액 / 월 납부액 |
