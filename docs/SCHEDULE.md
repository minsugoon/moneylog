# Moneylog 개발 스케줄 (초보자용)

- 버전: v0.6 / 최종 수정: 2026-10-31
- 변경(v0.6, 2026-10-31): 단계 7을 7-A~7-D로 나눔. 카드앱 "붙여넣기"를 "캡처 + AI"로 변경하고, 문자는 텍스트 붙여넣기(규칙 기반)로 먼저 만든다.
- 변경: 카드 실적 체크(단계 9), 실적 제외 표시(단계 10) 추가로 단계 번호 재정렬
- 변경(v0.4): 단계 4에 지출 메모와 하루 정리(일기) 추가, SQL 번호를 실행 순서대로 정리
- 변경(v0.5): PC/모바일 화면 틀과 PWA 설치를 단계 1~2로 앞당김. 단계 12는 오프라인·다크 모드 마무리

## 진행 규칙
1. 한 번에 한 단계만 한다.
2. 단계가 끝나면 "완료 확인"을 직접 해보고 → `git commit` + `git push`.
3. 막히면 에러 메시지를 통째로 Claude CLI에 붙여넣는다.
4. 망가지면 `git log`로 마지막 정상 커밋으로 돌아간다.
5. 큰 작업은 시작 전에 Claude CLI에게 "계획부터 말해줘"라고 먼저 시킨다.
6. 단계가 끝나면 폰 화면(약 400px)과 PC 화면(1280px 이상) 둘 다에서 확인한다.

## 전체 일정 (약 6주, 하루 1~2시간 기준)
| 주 | 단계 | 결과물 |
|----|------|--------|
| 1주 | 0~2 | 환경 준비, 빈 앱이 moneylog.vibecodelab.dev에 공개, 폰·PC 화면 틀, PWA 설치, 로그인 |

## 단계 7. 문자 인식 + 카드앱 캡처(AI) 입력 (v0.7에서 4개로 나눔)
상세 규칙은 `PARSER_SPEC.md`(샘플 포함), AI 키 준비는 `SETUP_GUIDE.md` 12장. 변경 이유: 카드앱 복사가 제각각이고 안 되는 앱이 있어 **캡처 + AI**로 바꿨고, 문자는 텍스트 붙여넣기(규칙 기반)로 먼저 만든다.
작업은 Claude가 명세를 쓰고 Codex가 구현한다 (`CLAUDE.md` 15장). 한 작업은 파일 8개·400줄 이하.

- [ ] 중복 판정: 지문(시각 포함), 개수 비교, "중복 가능" 후보 (`utils/`)
