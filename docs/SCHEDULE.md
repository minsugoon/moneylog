# Moneylog 개발 스케줄 (초보자용)

- 버전: v0.5 / 최종 수정: 2026-10-09
- 변경: 카드 실적 체크(단계 9), 실적 제외 표시(단계 10) 추가로 단계 번호 재정렬
- 변경(v0.4): 단계 4에 지출 메모와 하루 정리(일기) 추가, SQL 번호를 실행 순서대로 정리
- 변경(v0.5): PC/모바일 화면 틀과 PWA 설치를 단계 1~2로 앞당김. 단계 12는 오프라인·다크 모드 마무리

## 진행 규칙
1. 한 번에 한 단계만 한다.
2. 단계가 끝나면 "완료 확인"을 직접 해보고 → `git commit` + `git push`.
3. 막히면 에러 메시지를 통째로 Claude CLI에 붙여넣는다.
4. 망가지면 `git log`로 마지막 정상 커밋으로 돌아간다.
5. 큰 작업은 시작 전에 Claude CLI에게 "계획부터 말해줘"라고 먼저 시킨다.
6. 단계가 끝나면 폰 화면(약 400px)과 PC 화면(1280px 이상) 둘 다에서 확인한다.

## 전체 일정 (약 6주, 하루 1~2시간 기준)
| 주 | 단계 | 결과물 |
|----|------|--------|
| 1주 | 0~2 | 환경 준비, 빈 앱이 moneylog.dudeocode.com에 공개, 폰·PC 화면 틀, PWA 설치, 로그인 |
| 2주 | 3~4 | 결제수단 등록, 직접 입력, 내역 목록, 메모·하루 정리 |
| 3주 | 5~6 | 할부 계산, 고정지출, 보기 3종 → **MVP 완성** |
| 4주 | 7~8 | 붙여넣기·문자 인식, 고정지출 자동 인식 |
| 5주 | 9~10 | 카드 실적 체크, 실적 제외 표시 |
| 6주 | 11~12 | 파일 업로드, PWA, 다듬기, 정식 사용 시작 |

## 단계 4. 직접 입력 + 내역 목록 + 메모·하루 정리 (4일)
시작 전 `DATA_MODEL.md`의 **5번 SQL**(하루 정리 표) 실행.
- [ ] 입력 폼(사용일 기본 오늘, 결제수단 칩, 결제명, 금액, 할인, 취소 건 토글, 무이자 할부 토글)
- [ ] 저장 후 폼 비우기, 마지막 결제수단 기억
- [ ] 메모(선택, 200자 제한) 입력칸, 내역 목록·상세에서 메모 표시와 수정
- [ ] 입력 화면 하단 "오늘 하루 정리" 카드: 그날 지출 건수·합계 표시, 글 입력 시 자동 저장(upsert), 날짜를 바꾸면 그 날짜의 글을 불러옴
- [ ] 내역 목록: 날짜 아래에 하루 정리 표시, "+ 하루 정리"로 바로 쓰기, 지출 없는 날도 표시, 지우기 전 확인
- [ ] 내역 화면: 월 이동, 월 합계, 리스트, 수정/삭제(확인 포함)
- [ ] PC(1100px 이상): 내역·보기 화면 오른쪽에 "빠른 입력" 패널 (같은 입력 폼과 하루 정리 카드를 재사용)
- 완료 확인: 실제 이번 달 지출 10건을 폰으로 입력하고, 메모와 하루 정리를 한 편 써서 다음 날 다시 열어도 남아 있다

## 단계 7. 붙여넣기 · 문자 인식 (5일)
이 단계는 "내 실제 샘플"이 필요하다. 개인정보는 임의 숫자로 바꿔서 준비한다. 상세 규칙은 `PARSER_SPEC.md`.
- [ ] 카드 1~2개의 앱 내역 복사본, 결제 문자 5건, 은행 출금 문자 3건, 취소 문자 2건 준비
- [ ] 미리보기 표(체크/해제, 수정, 인식 실패 줄 빨간색). PC는 넓은 표, 모바일은 줄마다 카드 형태
- [ ] 결제수단 일괄 지정, 중복 감지
- [ ] 파서를 `utils/parsers/`에 카드사별 파일로 분리 + 테스트
- 완료 확인: 한 달 치 내역을 붙여넣어 90% 이상 맞게 인식되고, 같은 내용을 다시 붙여넣으면 "중복"으로 뜬다
